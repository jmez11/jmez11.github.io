Toolbars & sessions

Every session has a floating toolbar over its window. It shows the connection name, and you can drag it anywhere in the window.

The floating toolbar

  • Pin / Keep toolbar visible — otherwise the toolbar collapses. Double-tap to collapse it to an edge nub, drag the nub up or down, and tap its arrow to restore it.
  • In SSH, the toolbar hides after a few seconds unless pinned.

Desktop toolbar — RDP, VNC, and Mac

In order, the desktop toolbar offers:

  1. Connection name (or “Desktop N – name” when an RDP host has multiple monitors)
  2. Pin / Keep toolbar visible
  3. Window Manager (when available)
  4. Pick up content / Cancel content move — multi-monitor RDP only
  5. Add desktop — multi-monitor RDP only, when the host reports more than one monitor
  6. Mute / Unmute speakers — RDP always; for VNC only when Apple high-performance Mac streaming is active
  7. Browse files — VNC only, with a paired SSH connection that has file access enabled
  8. Mute / Unmute microphone — only when microphone redirection is on
  9. Mute / Unmute camera — only when camera redirection is on
  10. Zoom — 1×–3× slider plus Reset Zoom; above 1× a pan pad appears
  11. Transparency — window opacity slider
  12. Connection Info — when enabled in About, shows the profile, host, protocol, decoder, transport, canvas, and scale/zoom; for VNC also Mac auth mode and Apple streaming status
  13. Unlock with saved password — Mac only; confirms, then sends the saved Mac password
  14. Keyboard toggle — opens the on-screen keyboard and extra-key panel

For VNC, camera, microphone, storage redirection, and RemoteApp are not available. Sound plays on-device only with Apple Mac streaming and Mac audio enabled.

SSH / terminal toolbar

In order, the terminal toolbar offers:

  1. Connection name
  2. Pin / Keep toolbar visible
  3. Window Manager (when available)
  4. Zoom — terminal font size, with a reset to the profile default
  5. Transparency — terminal opacity slider
  6. Browse files — once an SFTP probe over the same SSH connection succeeds
  7. Port forwarding — opens the forwarding dialog, saved to the profile and applied live
  8. Keyboard toggle — the same on-screen keyboard and extra-key panel as desktop

Keyboard

The Keyboard toggle shows the on-screen keyboard plus a fixed extra-key panel: F1–F12, Win, Shift, Ctrl, Alt, AltGr, Del, Esc, Tab, Backspace, arrows, Home/End, Page Up/Down, Insert/Delete/Enter, Print Screen, and keypad symbols.

On a confirmed Mac, Win becomes Command, Alt becomes Option, AltGr becomes Right Option, Ctrl becomes Control, and Del becomes Forward Delete.

Disconnecting

To disconnect, use the Horizon OS X button on the system control bar below the window. There is no Disconnect button in Farside's own toolbars.

If a connection drops, a Reconnect dialog offers Reconnect or Cancel, and Reconnect Automatically is saved back to the connection. If a connection fails, a Connection failed dialog offers Close.
