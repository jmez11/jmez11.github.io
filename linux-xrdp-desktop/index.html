Linux XRDP Desktop

A full Ubuntu desktop in a container, over RDP.

A full Ubuntu 24.04 XFCE desktop in a Docker container, accessible over RDP — built for a fast, responsive remote Linux desktop that actually plays video smoothly.

Open source · MIT

GitHub

What you get

  • Ubuntu 24.04 + XFCE — Arc-Dark theme, Papirus icons, dark aurora wallpaper.
  • H.264 RDP encoding — xrdp 0.10.3 + xorgxrdp 0.10.3 built from source with x264 (Ubuntu's xrdp 0.9.x has no H.264 support). Smooth video playback and snappy window dragging at 1080p.
  • TLS-encrypted RDP on port 3389, with multi-monitor support.
  • Audio both ways — PulseAudio playback and microphone redirection over RDP.
  • Drive redirection — share client drives; they appear at ~/thinclient_drives/ via FUSE.
  • Clipboard redirection.
  • VirtualGL — GPU-accelerated OpenGL for headless servers (vglrun glmark2 to test).
  • Preinstalled apps — Firefox, VS Code, GIMP, Inkscape, VLC, LibreOffice, Blender, htop, neofetch, git.

Quick start

Deploy with Portainer: create a new stack, paste in the repo's docker-compose.portainer.yml, change RDP_PASS, and deploy. Or with Docker Compose:

  1. Clone the repo and edit docker-compose.portainer.yml to set RDP_PASS.
  2. Run docker compose -f docker-compose.portainer.yml up -d.
  3. Connect with any RDP client to <host>:3389 and log in.

The image is also published to ghcr.io/jmez11/linux-xrdp-desktop. Home directory persists in the rdp_home Docker volume. Pass /dev/dri through for GPU access.

Configuration

  • RDP_USER (default engineer) — desktop username, created on first start, has sudo.
  • RDP_PASS (default ChangeMe123!) — change this. Login password.
  • TZ (default UTC) — timezone.
  • LIBVA_DRIVER_NAME (default iHD) — VAAPI driver: iHD (Intel), radeonsi (AMD), omit for NVIDIA.

Client setup (mstsc)

Set these before connecting (Show Options):

  • Drives — Local Resources → More → Drives → tick your drives (appear at ~/thinclient_drives/).
  • Audio playback — Local Resources → Remote audio → Settings → Play on this computer.
  • Microphone — same dialog → Record from this computer.

Drive shares only take effect on a fresh login — if you tick them mid-session, log out of XFCE completely and reconnect.

Limitations

  • Webcams: xrdp has no video-capture channel, so client webcams can't be redirected over RDP. Microphone works; for video calls, use the client natively — or pass a host camera in with --device=/dev/video0.
  • RDP only: no VNC/SSH in this image by design; it's a single-purpose desktop container.

Full details, the Dockerfile, and the compose file are in the repo.
